\# Student Performance Analyzer



\## Overview



The Student Performance Analyzer is a Python-based console application developed as a CSE1021 Introduction to Problem Solving and Programming project.



The system is designed to manage student academic records, enter and update marks, analyze individual and class performance, and generate student performance reports.



\## Features



\- Add and manage student records

\- View stored student records

\- Search for students using Student ID

\- Update student information

\- Enter and update marks

\- Validate marks between 0 and 100

\- Calculate total and average marks

\- Determine grades and pass/fail results

\- Perform class-level analysis

\- Generate individual student performance reports



\## Subjects



The system currently supports four subjects:



\- CSE

\- Calculus

\- English

\- EVS
