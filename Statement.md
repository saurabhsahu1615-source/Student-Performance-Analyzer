\# Project Statement



\## Project Title



Student Performance Analyzer



\## Problem Statement



Students often have their academic marks stored or viewed individually, which makes it difficult to analyze overall performance in a structured manner. Calculating totals, averages, grades, and pass or fail results manually can also take additional time and may lead to errors.



The Student Performance Analyzer provides a structured Python-based system for managing student records and analyzing academic marks.



\## Objectives



\- Maintain student academic records in an organized manner.

\- Allow users to enter and update marks for different subjects.

\- Automatically calculate total marks and average marks.

\- Determine grades and pass/fail results.

\- Provide individual student performance analysis.

\- Provide class-level performance analysis.

\- Generate a structured student performance report.

\- Apply Python programming concepts through a modular project implementation.



\## Users



The system is intended for:



\- Students

\- Teachers



\## Subjects



The system currently supports four subjects:



\- CSE

\- Calculus

\- English

\- EVS



\## Main Features



\- Add student records

\- View student records

\- Search students using Student ID

\- Update student information

\- Enter and update marks

\- Validate marks between 0 and 100

\- Analyze individual student performance

\- Perform class-level analysis

\- Generate student performance reports



\## Input



The system accepts:



\- Student ID

\- Student name

\- Marks for CSE

\- Marks for Calculus

\- Marks for English

\- Marks for EVS



\## Output



The system provides:



\- Total marks

\- Average marks

\- Grade

\- Pass/fail result

\- Individual performance analysis

\- Class average

\- Highest and lowest performers

\- Grade distribution

\- Student performance report
